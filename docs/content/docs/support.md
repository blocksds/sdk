If you want to report any bugs or suggest new features and make sure they aren't
forgotten, use the BlocksDS Codeberg issue tracker.

{{< cards cols="1" >}}
  {{< card icon="codeberg" link="https://codeberg.org/blocksds/sdk/issues" title="Codeberg issue tracker" >}}
{{< /cards >}}

If you prefer to chat with other developers in real time, the best way is to
join one of the Discord servers where we hang out. The original home of BlocksDS is the
GBAdev Discord server, a community focused exclusively on homebrew development
for GBA and NDS. The DS⁽ⁱ⁾ Mode Hacking server is only for the NDS, but it isn't
only focused on homebrew development. Finally, the Wonderful Toolchain server
may be useful, as the compilers and associated libraries used by BlocksDS are
the ones built and distributed by Wonderful Toolchain.

{{< cards cols="1" >}}
  {{< card icon="discord" link="https://gbadev.net" title="GBAdev" >}}
  {{< card icon="discord" link="https://wiki.ds-homebrew.com/community/" title="DS⁽ⁱ⁾ Mode Hacking" >}}
  {{< card icon="discord" link="https://wonderful.asie.pl/wiki/doku.php?id=community" title="Wonderful Toolchain" >}}
{{< /cards >}}
